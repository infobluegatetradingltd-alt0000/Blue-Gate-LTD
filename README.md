## 🚀 Key Features

### 1. Motion-Led Hero & Apple-Inspired Polish
- Cinematic product stage highlighting flagship products with smooth interactive controls, subtle elevation, and accessibility compliance (`prefers-reduced-motion`).
- Apple-inspired product cards featuring high-clarity photography, calm neutral backgrounds, tactile hover states, and zero layout shift.

### 2. Department Catalogues & Seed Data
- **Electronics & Technology:** Pro ANC wireless headphones, Hall-Effect gaming controllers, AMOLED smartwatches, 65W GaN power banks, mechanical keyboards.
- **Toys & Games:** BS EN 71 certified STEM programmable coding robots, 1,280-piece architectural skyline sets, wooden mechanical puzzles.
- **Home & Everyday Essentials:** Modern LED task lamps, ultrasonic ceramic diffusers, precision 0.1g kitchen scales.
- **Lifestyle & Personal:** Minimalist RFID card wallets, double-wall thermal flasks, EVA travel cases.

### 3. Commerce Engine & Deterministic Calculations
- **Deterministic Math:** Subtotal, UK 20% VAT, promotional discounts (`BLUEGATE10`, `WELCOME5`), and £40.00 free tracked UK delivery threshold calculations.
- **Interactive Cart Drawer:** Real-time free shipping progress bar, promo code validation, stock cap checks, and item quantity controls.
- **Multi-Step Checkout:** Full UK postcode verification (`WV6 0SR`, `SW1A 1AA`, etc.), shipping method selection (Royal Mail 48 Tracked vs DPD Express), clearly marked sandbox card simulation, and printable order receipts.

### 4. UK Statutory & Regulatory Compliance
- **UK GDPR & PECR:** Cookie consent banner with granular preferences and explicit, unticked newsletter consent.
- **Consumer Rights Act 2015:** 30-day statutory returns policy with online RMA instructions.
- **Product Safety:** UKCA and CE conformity with British BS EN 71 toy safety directives.

## 📦 Getting Started

### Prerequisites
- Node.js (v20+)
- npm (v10+)

### Installation
```bash
git clone https://github.com/infobluegatetradingltd-alt0000/Blue-Gate-LTD.git
cd Blue-Gate-LTD
npm install --legacy-peer-deps
```

### Running Locally
```bash
# Start frontend development server (Vite)
npm run dev

# Start backend commerce API server
npm run server
```

### Automated Testing
```bash
npm test
```

### Production Build
```bash
npm run build
```
